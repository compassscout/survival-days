# 活过三十天 · 3D 生存模拟

> 单人纯前端 3D 生存游戏。**Three.js 低模城市、昼夜循环、天气系统**，断网也能玩（three.min.js 已内置，无外部请求）。
> 核心一句话：**你靠跑单为生，要在 30 天里活下去。** 钱难挣、熬夜伤身、饿着会晕，每个选择都有代价。

- 在线试玩：<https://compassscout.github.io/survival-days/>
- 仓库地址：<https://github.com/compassscout/survival-days>
- 当前版本：`1.0.0-3d`

---

## 这是什么

你扮演一个靠跑单赚钱的普通人，白天赚钱、吃饭、睡觉，在「活着」和「攒钱」之间反复做取舍。3D 版把这座城市做了出来：清晨日出、傍晚晚霞、深夜亮起的万家灯火；雨天路滑，电驴的车轮会转，饭摊会冒热气。

它是一面镜子，也是一道算术题：**什么都要，就什么都守不住。**

## 玩法

每天分成 **5 个时段**（清晨 → 上午 → 下午 → 傍晚 → 深夜），每个时段从 **6 个动作**里选 1 个执行。活过第 30 天触发结算，根据攒下的钱、健康、熬夜次数给出最终评价。

## 状态系统（6 项）

| 状态 | 满值 | 掉到 0 会 | 怎么恢复 |
|---|---|---|---|
| 饱腹 | 100 | 倒下，游戏结束 | 吃一顿 |
| 精力 | 100 | 倒下，游戏结束 | 睡觉 |
| 健康 | 100 | 倒下，游戏结束 | 睡觉 / 吃好 / 看医生 |
| 金钱 | 无上限 | 见底 → 压力飙升 | 跑单 / 作品上线 |
| 压力 | 100 | 越高越难熬 | 休息 / 睡觉 / 看医生 |
| 作品进度 | 100 | 满 100 自动结算稿费 | 做内容 |

## 六个动作

| 动作 | 收益 | 代价 |
|---|---|---|
| 🛵 跑单 | +45 元起（随等级/装备提升） | 精力、饱腹下降，压力上升 |
| 🍜 吃一顿 | 饱腹 +42 · 健康 +4 | -12 元 |
| 😴 睡觉 | 深夜睡回 70 精力 | 饱腹 -22 |
| 🌳 休息 | 压力 -14 | 略耗精力 |
| 🏥 看医生 | 健康 +34 | -45 元 |
| 💻 做内容 | 作品进度 +26 起 | 精力、饱腹下降 |

## 3D 版新增

- **随机事件**：差评扣款、顾客打赏、逆行罚单、雨天摔跤、老板送鸡腿、灵感爆发
- **商店装备**（永久生效）：🌂 雨衣 · 🥤 保温杯 · 🎧 降噪耳机 · 🏋️ 健身月卡 · 🛵 二手电动车 · 💻 二手电脑
- **技能成长**：跑单 Lv 提升单价，创作 Lv 提升进度与稿费
- **天气系统**：随机雨天，影响跑单收入与安全
- **昼夜循环**：5 个时段对应 5 种天色，深夜路灯与楼窗亮灯

## 本地运行

下载本仓库，`index.html` 与 `three.min.js` 保持在同一目录，双击 `index.html` 即可。

## 技术栈

原生 HTML/CSS/JS + Three.js r128（本地内置），零构建、零依赖、零后端。
