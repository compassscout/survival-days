# 活过三十天 · 生存模拟

> 单人纯前端生存游戏。**零依赖、零后台、零外部请求**，一个 HTML 文件即玩，断网也能跑。
> 核心一句话：**你靠跑单为生，要在 30 天里活下去。** 钱难挣、熬夜伤身、饿着会晕，每个选择都有代价。

- 在线试玩：<https://compassscout.github.io/survival-days/>
- 仓库地址：<https://github.com/compassscout/survival-days>
- 当前版本：`0.1.0`

---

## 这是什么

你扮演一个靠跑单赚钱的普通人，白天赚钱、吃饭、睡觉，在「活着」和「攒钱」之间反复做取舍。没有华丽的养成，只有赤裸裸的数值平衡：多跑单就有钱，但会饿、会累、会垮；睡觉能回精力，但钱就停在那儿了。

它是一面镜子，也是一道算术题：**什么都要，就什么都守不住。**

## 玩法

每天分成 **5 个时段**（清晨 → 上午 → 下午 → 傍晚 → 深夜），每个时段从 **6 个动作**里选 1 个执行。活过第 30 天触发结算，根据攒下的钱、健康、熬夜次数给出最终评价。

## 状态系统（6 项）

| 状态 | 满值 | 掉到 0 会 | 怎么恢复 |
|---|---|---|---|
| 饱腹 | 100 | 倒下，游戏结束 | 吃一顿 |
| 精力 | 100 | 倒下，游戏结束 | 睡觉 |
| 健康 | 100 | 倒下，游戏结束 | 睡觉 / 吃好 / 看医生 |
| 金钱 | 无上限 | 见底 → 压力飙升 | 跑单 / 作品上线 |
| 压力 | 100 | 越高越难熬 | 休息 / 睡觉 / 看医生 |
| 作品进度 | 100 | 满 100 自动结算 +200 元 | 做内容 |

## 六个动作

| 动作 | 收益 | 代价 |
|---|---|---|
| 跑单 | +52 元 | 精力、饱腹下降，压力上升 |
| 吃一顿 | 饱腹 +40，健康 + | 花 12 元 |
| 睡觉 | 精力大幅恢复（深夜睡效果最好） | 耗饱腹 |
| 休息 | 压力下降 | 略耗精力 |
| 看医生 | 健康 +34 | 花 45 元 |
| 做内容 | 作品进度 +26 | 耗精力、饱腹 |

## 机制细节

- **熬夜惩罚**：深夜时段不睡觉 = 熬夜。第二天精力、健康掉，熬得越多垮得越快。
- **低血糖**：饱腹过低时跑单会一阵晕眩，健康大掉。
- **连锁垮掉**：钱见底 → 压力升 → 越睡不好 → 健康流失，崩盘会滚雪球。
- **小人状态**：角色会随健康 / 精力 / 金钱改变表情（生病、疲惫、忧愁、正常）。
- **昼夜反馈**：太阳 / 月亮随时段切换，操作日志实时滚动。

## 界面说明

- 顶部：第几天 / 哪个时段 + 天数进度条。
- 中部：场景区（小人 + 昼夜）+ 六项状态条。
- 下部：六个动作按钮 + 实时日志 + 规则提示。
- 桌面端三列状态，移动端两列，响应式适配。

## 技术实现

单文件结构（HTML + CSS + JS 全内联），无构建、无框架、无外部库：

| 位置 | 作用 |
|---|---|
| `S` 对象 | 全部状态与初始值 |
| `ACTIONS` 数组 | 动作定义（名称 / 收益 / 图标） |
| `doRun … doWork` | 六个动作的效果逻辑 |
| `advance()` | 时段推进、新一天结算、熬夜惩罚 |
| `checkDeath()` | 结束判定（三态归零） |
| `render() / renderPerson()` | 状态条 / 小人表情渲染 |
| `finish()` | 第 30 天结算与评级 |

## 修改与扩展

- **调数值**：改 `S` 初始值，或各 `doXxx` 里的增减。
- **加动作**：往 `ACTIONS` 加一项 + 写对应函数。
- **加随机事件**：参照 `doRun` 里的 `Math.random()` 分支。
- **改天数**：改 `GAME_DAYS`。
- 改完直接刷新浏览器即可生效。

## 部署到 GitHub Pages

仓库已就绪，开启只需两步：

1. 仓库 **Settings → Pages**。
2. **Source** 选 **Deploy from a branch** → 分支 **main** → 目录 **/(root)** → **Save**。

部署完成后站点：`https://compassscout.github.io/survival-days/`。

> 404 排查：确认 Source 是 `Deploy from a branch` 而非 `GitHub Actions`；确认分支是 `main`；开启后等 1–2 分钟部署跑绿（Actions 里有 `github-pages` 记录）。

## 常见问题

**点开地址是 404？**

GitHub Pages 还没开启或还在部署。按上面「部署到 GitHub Pages」两步开启，等部署记录变绿再访问。

**总是很快死掉？**

初期最稳的打法是「跑单 + 按时吃饭 + 深夜准时睡觉」，健康低了及时看医生。想攒钱就别连熬，熬夜的账第二天加倍还。

**想加功能？**

见「修改与扩展」。单文件改起来很快。
