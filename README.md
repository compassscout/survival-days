# 活过三十天 · 生存模拟

一个单人纯前端生存模拟游戏。**没有后台、没有依赖、零外部资源**——一个 HTML 文件就能跑，双击即玩。

核心就一句话：**你靠跑单为生，要在 30 天里活下去。** 钱难挣、熬夜伤身、饿着会晕，每个选择都有代价。

## 在线试玩

👉 **https://compassscout.github.io/survival-days/**

（仓库开启 GitHub Pages 后此地址生效，源文件为 `index.html`）

---

## 这是什么

你扮演一个靠跑单赚钱的普通人，白天赚钱、吃饭、睡觉，在「活着」和「攒钱」之间反复做取舍。
没有华丽的养成，只有赤裸裸的数值平衡：多跑单就有钱，但会饿、会累、会垮；睡觉能回精力，但钱就停在那儿了。

## 状态系统（6 项）

| 状态 | 满值 | 掉到 0 会 | 怎么恢复 |
|---|---|---|---|
| 饱腹 | 100 | 倒下 | 吃一顿 |
| 精力 | 100 | 倒下 | 睡觉 |
| 健康 | 100 | 倒下 | 睡觉 / 吃好 / 看医生 |
| 金钱 | 无上限 | 钱包见底 → 压力飙升 | 跑单 / 作品上线 |
| 压力 | 100 | （越高越难熬） | 休息 / 睡觉 / 看医生 |
| 作品进度 | 100 | 满 100 自动结算 +200 元 | 做内容 |

## 玩法规则

- 每天分成 **5 个时段**：清晨 → 上午 → 下午 → 傍晚 → 深夜。
- 每个时段从 **6 个动作**里选 1 个执行。
- **深夜不睡觉 = 熬夜**：第二天精力、健康都会掉，熬得越多垮得越快。
- **饿着跑单有低血糖风险**：饱腹过低时跑单会晕，健康大掉。
- **饱腹 / 精力 / 健康** 任一归零，角色倒下，游戏结束。
- **活过第 30 天** 触发结算，根据攒下的钱、健康、熬夜次数给出最终评价。

## 六个动作

| 动作 | 收益 | 代价 |
|---|---|---|
| 跑单 | +52 元 | 精力、饱腹下降，压力上升 |
| 吃一顿 | 饱腹 +40，健康 + | 花 12 元 |
| 睡觉 | 精力大幅恢复（深夜睡效果最好） | 耗饱腹 |
| 休息 | 压力下降 | 略耗精力 |
| 看医生 | 健康 +34 | 花 45 元 |
| 做内容 | 作品进度 +26 | 耗精力、饱腹 |

## 本地运行

```
双击 index.html 打开即可，无需服务器、无需联网。
```

## 修改 / 开发

单文件结构，全部逻辑在 `index.html` 的 `<script>` 里：

- 状态与初始值 → `S` 对象
- 动作定义 → `ACTIONS` 数组
- 动作效果 → `doRun / doEat / doSleep / doRest / doDoc / doWork`
- 每天结算与熬夜惩罚 → `advance()`

改完直接刷新浏览器即可看到效果。

## 部署到 GitHub Pages

仓库已经就绪，开启 Pages 只需两步：

1. 仓库 **Settings → Pages**
2. **Source** 选 **Deploy from a branch** → 分支 **main** → 目录 **/(root)** → **Save**

部署完成后站点地址为：`https://compassscout.github.io/survival-days/`
