# 城市漫游 · City Wander

> 单人纯前端 3D 漫游探索游戏。低多边形城市、昼夜调节、故事收集。
> 没有生存压力，没有数值——只是在城里走，读完 12 个街角故事。

- 在线试玩：<https://compassscout.github.io/survival-days/>
- 仓库地址：<https://github.com/compassscout/survival-days>
- 当前版本：`2.0.0-city`（推翻重建：由生存模拟改为漫游探索）

---

## 这是什么

一座程序化生成的低多边形城市：纵横路网、十字路口斑马线、错落高矮的浅灰楼房、沿路的树与路灯。你控制一个小人慢慢走，靠近城市里 12 个发光的金色标记点，就能读到 12 个街角故事——早餐铺、馄饨摊、旧书报亭、城墙根……

看过的光点会变成灰蓝色，进度存在 localStorage，关掉页面也不会丢。

## 操作

| 按键 | 作用 |
|---|---|
| WASD | 移动（相对镜头方向） |
| Shift | 快跑 |
| 鼠标拖拽 | 旋转视角 |
| 滚轮 | 缩放距离 |
| 顶部滑块 | 调节昼夜（0–24 时，入夜路灯点亮） |

## 本地运行

下载本仓库，双击 `index.html` 即可（需联网加载 Three.js CDN）。

## 技术要点

- 单 HTML 文件，Three.js r128 CDN 引入，零构建、零依赖、零后端
- 全部场景物体只用 Box / Cone / Cylinder / Sphere 基础几何体拼装，无外部贴图与模型
- 程序化城市：固定种子（mulberry32），每次打开布局不变
- 哑光低饱和配色 + 距离雾 + PCFSoft 柔和阴影
- 圆形玩家 vs AABB 建筑碰撞检测，不穿墙
- localStorage 保存探索进度

## 技术栈

原生 HTML/CSS/JS + Three.js r128（CDN）。
